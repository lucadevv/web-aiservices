# AI Services

Storefront for AI services with **Stripe checkout**, built with **Next.js** and TypeScript.

## Tech Stack

- **Next.js / React / TypeScript**
- **Stripe** (`@stripe/stripe-js`, `@stripe/react-stripe-js`) — payments & checkout
- **Tailwind CSS** + **Radix UI** — styling & components
- **lucide-react** — icons

## Getting Started

```bash
npm install
npm run dev
```

> Set your Stripe publishable key in the environment before running.
